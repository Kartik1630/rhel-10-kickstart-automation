# RHEL 10 Kickstart Installation Guide

## Requirements

- RHEL 10 ISO
- VMware Workstation 17
- 4 GB RAM
- 40 GB virtual disk
- Local Kickstart media

## Installation

1. Create a RHEL 10 VM.
2. Prepare ks.cfg.
3. Attach the Kickstart media.
4. Boot the RHEL installer.
5. Add the inst.ks boot parameter.
6. Start automated installation.
7. Verify the installed system.
